📋 ТЗ: Market Watcher (CLI Dashboard)
🎯 Цель
Создать CLI-приложение (интерфейс командной строки), которое:
Получает текущие курсы валют (Crypto & Fiat) через бесплатные API без токенов.
Сравнивает их с порогами, заданными в конфигурации.
Выводит красивое "Сводное табло" в консоль (в стиле хакера/трейдера).
Сохраняет историю изменений в JSON, если цена изменилась более чем на X%.
🛠️ Технологии
Python 3
OOP (Классы: Fetcher, Analyzer, Reporter)
Библиотеки: requests (только она), встроенные json, datetime, os.
Стиль: "Dark Mode" консоль, минимализм.
📁 Структура проекта (Скелет)
Используем ту же архитектуру, что и в ip-detector:

market-watcher/
├── src/
│   └── core/
│       ├── price_fetcher.py   # Логика запросов к API
│       ├── analyzer.py        # Логика сравнения цен и алертов
│       └── reporter.py        # Логика сохранения JSON
├── config.py                  # Настройки (пороги цен)
├── main.py                    # Точка входа
└── requirements.txt           # requests

🔌 API (Бесплатно, без ключей!)
Крипто: https://api.coincap.io/v2/assets/bitcoin (Цена BTC)
Валюта: https://api.exchangerate-api.com/v4/latest/USD (Курс USD/RUB)
📝 Задачи по шагам:
Конфигурация (config.py):
Задать "Пороги" (Thresholds). Например:
btc_alert_threshold: 5000 (если цена упала или выросла сильно).
target_currency: "RUB".
Fetcher (src/core/price_fetcher.py):
Класс, который делает GET-запросы к обоим API.
Возвращает чистые данные (словарь: {'btc_usd': 65000, 'usd_rub': 92.5}).
Обработка ошибок (если API недоступен).
Analyzer (src/core/analyzer.py):
Принимает текущие цены и настройки.
Считает "Изменение" (можно сделать рандомную симуляцию для теста, если API дает только текущую цену, или просто сравнивать с конфигом).
Определяет статус: STABLE, SPIKE (взлет), DROP (падение).
Reporter (src/core/reporter.py):
Формирует итоговый словарь (Время, BTC, USD, Статус).
Сохраняет в файл reports/history.json.
Выводит красивую сводку в консоль (используй print с цветами, если хочешь, или просто эмодзи).
Main (main.py):
Связывает всё воедино.
Запускает процесс.
