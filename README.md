# IP Detector

Курсовой проект: определение геолокации по IP и загрузка отчёта на Яндекс.Диск.

## Запуск
1. Склонируй репозиторий
2. Создай venv: `python -m venv venv`
3. Активируй: `.\venv\Scripts\Activate` (Win) / `source venv/bin/activate` (Linux/Mac)
4. Установи зависимости: `pip install -r requirements.txt`
5. Заполни `.env` токенами (см. `.env.example`)
6. Запусти: `python main.py`
